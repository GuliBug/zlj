## 四、本轮发现并修复的缺陷（含 UI 级回归发现）

| 编号 | 现象 | 根因 | 修复 | 回归结果 |
|---|---|---|---|---|
| BUG-01 | 收货地址手机号可填非法值 | AddressService 未做手机号格式校验 | 增加 `^1\d{10}$` 与必填校验（FR-08-1） | 通过 |
| BUG-02 | 售后时间线缺少「系统受理」节点，双端时间线不完整 | 申请时仅写入「买家提交」一条流转记录 | 申请成功后追加「系统受理」记录（FR-06-5） | 通过 |
| BUG-03 | 新增商品/盘点单接口不返回主键，前端无法定位与二次操作 | Controller 返回 `AjaxResult<Void>` | 返回 `{id}`（AC-10 / AC-11） | 通过 |
| BUG-04 | 重复执行 E2E 时商品条码冲突 | 测试数据使用固定条码 | 条码改时间戳唯一值（用例缺陷，非产品缺陷） | 通过 |
| BUG-05 | 盘点单提交人自确认报「系统繁忙」而非明确原因 | 请求主键为空导致类型转换异常 | 创建接口返回 id 后按正常路径校验，提示「提交人不得同时担任确认人」 | 通过 |
| BUG-06 | 购物车「结算」按钮被底部 TabBar 完全遮挡，无法下单（用户实测发现，UI 级用例 UC-03 拦截） | .bottom-bar 与 TabBar 均 fixed bottom:0 且 TabBar z-index 更高 | 新增规则 .has-tabbar .bottom-bar { bottom: 52px } 抬升结算栏并同步底部留白（H5-09） | 通过 |
| BUG-07 | 订单详情「商品清单」「收货信息」区块空白（用户实测发现） | 后端订单详情接口未返回 items 明细 | orderDetailVo 补充 items（skuId/name/image/flavor/spec/price/quantity/subtotal） | 通过 |
| BUG-08 | H5/Web 页面与交互原型差距大（用户实测反馈） | 实现未以原型为基准逐页对齐 | 双端按原型逐页重做（H5 品牌导航/四宫格/分档/核销码页/4Tab；Web 7菜单/三步新增商品/今日概览/会员等级卡），种子数据同步对齐原型门店/分类/商品 | 通过 |

## 七、未覆盖项与后续建议

1. **支付/短信真实通道**：待 RK-01 类目报备通过后接入，替换通道实现并重跑资金链路用例；
2. **15 分钟超时关单**：建议提供可配置超时参数（当前 30s 扫描 + 15 分钟阈值），联调环境用短阈值回归；
3. **并发压测**：建议 100 QPS 下单压测，验证乐观锁与连接池；
4. **T+1 对账**：接入渠道账单文件解析，差异表与告警闭环；
5. **兼容性**：H5 需真机回归 iOS Safari 14+/微信内置浏览器；
6. **RBAC**：本期按决策移除，多角色授权依赖人工约定，团队扩编前建议恢复。
