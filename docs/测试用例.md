## 五、关键用例步骤示例

### 1. 下单幂等（FR-04-2）
1. 买家登录，加购 SKU，携带 `idempotentKey=K` 提交订单 → 返回订单号 N1；
2. 5 分钟内以同一 K 再次提交 → 期望返回同一订单号 N1，订单总数不增加。

### 2. 库存预占与缺货（FR-04-3 / E-03）
1. 记录 SKU 可用库存 S；下单数量 q → 期望可用库存 = S-q（预占）；
2. 下单数量 99999 → 期望返回「库存不足，剩余可购 X」，库存不变（整单回滚）。

### 3. 到店自提核销（FR-04-8 / ST-02 / ST-03）
1. 自提下单 → 运费 0 → 支付 → 订单状态 `PICKUP_WAIT`；
2. `GET /api/orders/{no}/verify-code` 返回 6 位码，错误码核销被拒（明确原因）；
3. 正确码核销 → 订单 `COMPLETED`、库存实扣、核销记录可查（店员/时间/门店）。

### 4. 退款幂等（FR-13-4）
1. 售后审核通过 → 调 `POST /admin-api/aftersales/{no}/refund` 成功 → 状态 `REFUNDED`、退款单号 `AS...-1`；
2. 再次调用同接口 → 返回成功但不生成新退款单（`-1` 不变），不重复扣款。

### 5. 盘点二级审批（FR-11-3）
1. admin 创建盘点单（实盘数≠账面数，差异自动计算）；
2. admin（提交人）确认 → 期望被拒「提交人不得同时担任确认人」；
3. manager（第二人）确认 → 按差异修正库存并生成 `ADJUST` 流水。
