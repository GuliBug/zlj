## Context

H5 侧为 Home.vue（品牌导航 + 警示条 + hero + 四宫格 + 分档 chips + 双列网格）、Category.vue（按顶级分类分节网格）、ProductDetail.vue（SKU 弹层 + 吸底栏 + 合规文案块）；Web 管理端为 views/product/index.vue（列表筛选/导出）与 edit.vue（三步新增/编辑、SKU 笛卡尔积、违禁词实时校验）。

## Goals / Non-Goals

**Goals:**

- 记录商品域前端基线交互口径（图片兜底、SKU 交互、合规展示、管理端三步流程）。

**Non-Goals:**

- 不改动任何代码；不引入门店切换（单店模式，见 202610-单店模式收敛）。

## Decisions

### FD1 商品图统一走 GoodsMedia 兜底

图片为空或 404 时渲染渐变红底品牌占位块（楷体首字），全站不出现破图；列表角标展示当前分类名。

### FD2 SKU 弹层交互

底部弹出；单 SKU 有货自动选中；缺货 SKU 置灰标注「（缺货）」；数量步进受实时库存上限；加购成功 Toast + 角标刷新（99+ 封顶）；「立即购买」经 `store.buyNow` 直达结算页，用后即清防刷新复用。

### FD3 已下架商品吸底栏降级

`status=OFF` 时吸底栏替换为置灰「商品已下架」，不提供任何购买入口。

### FD4 管理端新增商品三步流程

基本信息 → SKU 与价格 → 图片与详情；名称/描述输入时调用 check-banned-words 实时校验，命中红字提示并阻断提交；SKU 支持口味×规格笛卡尔积快捷生成与批量填充。

### FD5 契约疑问章节

无疑问：接口字段与契约一致。
