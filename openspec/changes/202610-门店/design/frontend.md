## Context

H5 侧 Stores.vue（门店信息纯展示）与结算自提块、核销码页的门店展示；Web 管理端 views/store/index.vue（单店列表 + 编辑弹窗 + 核销操作面板 + 核销记录，202610-单店模式收敛已移除新增入口）。

## Goals / Non-Goals

**Goals:**

- 记录门店前端基线交互口径（纯展示、单店锁定、核销面板）。

**Non-Goals:**

- 不改动任何代码；不恢复 H5 门店切换。

## Decisions

### FD1 H5 门店页纯展示

仅渲染名称/地址/电话/营业时间与状态（CLOSED 半透明 +「休息中」），无任何切换交互；进入页面时 `applyDefaultStore` 同步全局默认门店，供结算与核销码页使用。

### FD2 结算自提锁定默认门店

自提模式下不展示门店选择，直接展示默认门店信息（名称/地址/到店报手机尾号核销）——单店模式下选择器无意义。

### FD3 Web 核销面板与记录一体

核销操作面板（订单号 + 6 位码）与核销记录同页；记录支持按码/手机尾号与日期过滤（接口不支持时前端过滤当页）；待自提记录「扫码核销」一键预填订单号。

### FD4 契约疑问章节

无疑问：门店字段与核销接口和契约一致（operatingHours 已在 AC-02/AC-12 契约内）。

## Risks / Trade-offs

- [门店编辑的营业时间依赖后端识别] → 编辑弹窗内已注明「后端不识别时该字段不生效」；契约 AC-02 已含 operatingHours，口径一致。
