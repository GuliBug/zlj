## ADDED Requirements

### Requirement: ST-05 H5 门店信息页
H5 门店页 SHALL 纯展示门店列表（名称/地址/电话/营业时间），单店模式仅展示默认门店且不提供切换；停用门店半透明展示并标注「休息中」；页内说明门店数据由运营后台维护；进入页面时将默认门店同步到全局状态（供结算自提与核销码页使用）。

#### Scenario: 停用门店展示
- **WHEN** 门店状态为 CLOSED
- **THEN** 卡片半透明展示并附「休息中」标注

### Requirement: ST-06 Web 门店管理页
Web 门店页 SHALL 单店模式：仅展示默认门店（附主店标签）与「编辑」入口，不提供新增/切换/删除；编辑弹窗维护名称（必填）/地址（必填）/电话/营业时间/状态（营业中/筹备中停用），保存后即时生效并同步 H5。

#### Scenario: 无新增入口
- **WHEN** 管理员打开门店管理页
- **THEN** 仅见唯一门店的编辑操作，无新增按钮，页内展示单店模式说明

### Requirement: ST-07 核销操作与记录
Web 门店页 SHALL 提供核销操作面板（输入订单号 + 6 位核销码提交核销，成功/失败以结果提示条展示）与核销记录列表（订单号/门店/商品/金额/核销时间/待自提或已核销状态，支持按核销码或手机尾号关键字与日期过滤、分页）；待自提记录提供「扫码核销」一键预填；页内说明核销规则与留痕不可删除。

#### Scenario: 核销失败提示
- **WHEN** 核销码错误或订单与门店不匹配
- **THEN** 面板以错误样式展示后端返回的失败原因

#### Scenario: 待自提预填核销
- **WHEN** 店员点击待自提记录的「扫码核销」
- **THEN** 核销面板自动预填该笔订单号
