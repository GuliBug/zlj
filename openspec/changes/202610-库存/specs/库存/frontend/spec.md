## ADDED Requirements

### Requirement: FR-11-8 库存总览页
Web 库存页「库存总览」 SHALL 按 SKU 展示实物/预占/可用/冻结四列与安全阈值，可用低于阈值标红并渲染状态标签（充足/低于阈值/紧急预警（可用≤10）/已冻结）；支持关键字（SKU/条码/商品名）与「仅看预警/仅看冻结」筛选及分页；页内固定说明库存口径（实物=可用+预占+冻结）与扣减链路。

#### Scenario: 状态标签渲染
- **WHEN** 某 SKU 可用库存为 5 且未冻结
- **THEN** 该行展示「紧急预警」红色标签且可用数标红

#### Scenario: 预警筛选
- **WHEN** 选择「仅看预警」并查询
- **THEN** 列表仅展示可用 ≤ 阈值或已冻结的 SKU

### Requirement: FR-11-9 入库/冻结/阈值操作
总览页 SHALL 提供入库（指定 SKU 与数量）、冻结/释放（弹窗填写原因后提交，FREEZE/RELEASE 二态切换）与阈值修改（行内弹窗回显当前值）入口；操作成功后刷新列表与状态标签，阈值修改提示留审计。

#### Scenario: 冻结操作
- **WHEN** 管理员对未冻结 SKU 填写原因提交冻结
- **THEN** 该 SKU 状态标签变为「已冻结」，操作列切换为「释放」

### Requirement: FR-11-10 库存流水查询
「库存流水」 SHALL 支持 SKU ID 与流水类型筛选，展示时间/类型（正负着色标签）/SKU/±变动/变动后可用/关联单号/操作备注及分页；页内说明流水不可删改、日终按「实物=Σ流水」核对、差异告警。

#### Scenario: 流水检索
- **WHEN** 按某 SKU 与类型 OUT 查询流水
- **THEN** 返回该 SKU 出库类流水的分页列表，变动列负值红色展示

### Requirement: FR-11-11 盘点单页
「盘点单」 SHALL 展示盘点单列表（单号 PD+id/SKU 的系统数/实盘数/差异/状态/提交人与确认人）并支持发起盘点；未确认的盘点单展示「确认修正」入口，确认前弹窗说明提交人不得自任确认人（后端拒绝自确认）；确认成功后按差异修正库存并生成「盘点修正」流水。

#### Scenario: 差异着色
- **WHEN** 盘点单存在差异
- **THEN** 盘盈绿色「+N」、盘亏红色「-N」展示，差异为 0 不着色
