```
proposal.md / design.md / tasks.md（单文件）+ specs/<英文能力>/spec.md（不分端）
```

```
proposal.md + api.md + specs/<能力>/<端>/spec.md + design/backend|frontend.md + tasks/backend|frontend.md
```
