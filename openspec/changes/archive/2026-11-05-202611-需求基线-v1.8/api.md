# 接口文档

## 结论：无接口变更

本 change 仅做**需求资产入库与引用路径修正**，不新增、不变更、不废弃任何接口。

### 判断依据

1. **无代码改动**：本次变更不触碰 `backend/` 任何源码，也不触碰 `frontend-web/`、`frontend-h5/` 任何源码；产物全部为 Markdown 文档与 HTML 原型文件。
2. **无字段口径变化**：PRD v1.8 的 FR-01~FR-16 编号、字段定义、状态机枚举、金额单位（分）、时间格式（ISO）全部沿用既有实现，未做任何调整；PRD 文件内容逐字节复制入库，未作编辑。
3. **无契约来源变化**：`openspec/specs/接口契约/backend/spec.md` 所定义的 URL、鉴权、请求/响应字段表与错误码全部不变，本次不动该主规格。
4. **涉及接口清单（消费其他模块接口）**：无。本 change 不消费任何接口。

### 与后端主规格的关系

后端规格的业务口径以 PRD FR 编号为追溯锚点（如 `FR-04-2 下单幂等`、`FR-13-4 退款幂等`）。本次 PRD 的**存放位置**从仓库外路径变更为仓库内路径，**锚点编号与语义完全不变**，故不产生任何 delta。

### 契约同步

本次无接口变更，`接口契约/backend/spec.md` 无需更新；归档时亦无需同步定稿契约。
