## Context

Web 库存页 views/stock/index.vue：三个 Tab（库存总览/库存流水/盘点单），顶部「入库/发起盘点」快捷入口；总览含关键字与「仅看预警/仅看冻结」筛选、状态标签、行内入库/冻结释放/阈值操作。

## Goals / Non-Goals

**Goals:**

- 记录库存前端基线交互口径（状态标签分级、口径说明内嵌、流水检索）。

**Non-Goals:**

- 不改动任何代码；不做移动端适配（管理端仅桌面）。

## Decisions

### FD1 状态标签四级

充足（绿）/低于阈值（黄，available ≤ threshold）/紧急预警（红，available ≤ 10）/已冻结（灰）；可用数在低于阈值时标红，一眼定位风险 SKU。

### FD2 口径说明内嵌页面

总览页固定说明恒等式与扣减链路，流水页固定说明「不可删改、关联单号、日终核对」——降低新人理解成本，不依赖外部文档。

### FD3 冻结/释放弹窗填原因

FREEZE/RELEASE 二态按钮切换，弹窗填写原因（FreezeBody.reason）后提交；阈值按钮回显当前值修改，提交后提示留审计。

### FD4 盘点确认防自盘自改

「确认修正」按钮仅未确认状态展示，确认弹窗明示「提交人不得同时担任确认人，若您是提交人后端将拒绝」。

### FD5 契约疑问章节

无疑问：四维字段/流水类型枚举/盘点结构均与契约一致。

## Risks / Trade-offs

- [冻结弹窗未做二次确认框] → 冻结可随时释放、影响面小，采用单弹窗填原因即可；退款类高危操作才用双重确认。
