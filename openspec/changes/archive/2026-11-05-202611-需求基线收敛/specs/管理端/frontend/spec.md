## MODIFIED Requirements

### Requirement: WA-18 页面结构对齐 Web 管理端原型
Web 管理端 SHALL 以 PRD v1.0 附录 A.2「Web 管理端信息架构」为结构基准：侧栏 7 菜单（工作台/商品管理(商品列表+新增商品)/库存/门店/订单/售后/会员），审计与告警自工作台资损监控入口进入；主色 #8f1d22、侧栏 #241d18；工作台含 4 指标卡与今日概览表；新增/编辑商品为独立页面（三步步骤条、SKU 快捷生成与批量填充、违禁词实时校验、库存货值列）；门店页含营业时间维护与核销记录。

#### Scenario: 新增商品三步流程
- **WHEN** 管理员在商品管理点「新增商品」
- **THEN** 进入独立页面按 基本信息→SKU与价格→图片与详情 三步填写，名称/描述输入时实时违禁词校验，命中即红字提示并阻断提交
